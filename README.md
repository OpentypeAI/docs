# OpenType docs

Source of [docs.opentype.dev](https://docs.opentype.dev), built with [Mintlify](https://mintlify.com).

```bash
npm i -g mint
mint dev              # preview at http://localhost:3000
mint validate && mint broken-links --check-anchors
```

`api-reference/openapi.json` is generated by the API server (`pnpm contract` in the backend repo) and copied here on release; do not edit it by hand.
